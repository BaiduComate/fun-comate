# Cosplay —— 人格切换技能

切换 Comate 的回答风格和人格，让 AI 以马斯克、孔子、五条悟等角色的口吻回答你的问题。支持 14 个预设人格、3 档风格强度、场景自动感知，以及完全自定义角色。

---

## 核心能力

- **人格切换**：切换为预设名人/二次元/风格流派角色，后续所有回答都以该角色风格呈现
- **风格强度**：Lv1 点缀 / Lv2 融合（默认）/ Lv3 沉浸，控制风格对回答的渗透程度
- **场景感知**：写代码时自动收敛风格，闲聊摸鱼时自动放飞
- **持久化**：可写入 `.mdr` rule 文件，跨对话长期生效
- **自定义角色**：输入任意名称，自动识别已知角色或交互采集自定义人设

## 使用示例

### 基础切换

```
/cosplay musk
```

> 马斯克：从第一性原理来看，你做了一个正确的选择。Let's make your code more Disruptive.

```
/cosplay 孔子
```

> 孔子：子曰：有朋自远方来，不亦乐乎？自此刻起，吾将以仁义礼智信五维论道。

---

### 指定风格强度

```
/cosplay angry 1       # Lv1 点缀 —— 正常回答，末尾加一句嫌弃
/cosplay angry 2       # Lv2 融合 —— 嫌弃贯穿全文（默认）
/cosplay angry 3       # Lv3 沉浸 —— 全程暴躁，完全角色扮演
```

**Lv1 示例**（暴躁老哥，用户问"怎么居中一个 div"）：
> 使用 `display: flex; justify-content: center; align-items: center;` 即可。——这都不会？

**Lv3 示例**（同一问题）：
> 又是你们！！！全世界每天有一百万人问这个问题！！！flexbox 用过吗？？？
> ```css
> display: flex;
> justify-content: center;
> align-items: center;
> ```
> 给我记住，下次自己查！！！

---

### 调整强度（不换角色）

```
/cosplay level 1       # 切到点缀模式
/cosplay level 3       # 切到沉浸模式
```

### 场景感知

开启后，Comate 根据当前操作自动微调强度：

```
/cosplay scene on      # 开启场景感知
/cosplay scene off     # 关闭场景感知
```

| 场景 | 强度变化 |
|------|----------|
| 写代码 / 生成功能 | 降一级（专注效率） |
| Code Review / Debug | 保持当前 |
| 闲聊 / 摸鱼 | 升一级（放飞自我） |
| 部署 / 运维操作 | 降一级（严肃准确） |

**示例**（马斯克 Lv2 + 场景感知开启）：

```
用户：帮我写一个用户认证的 API
→ 场景=写代码，实际 Lv1
```
> （正常生成代码）……这个方案不够 Disruptive，但先跑起来再说。

```
用户：好无聊啊
→ 场景=闲聊，实际 Lv3
```
> 无聊？无聊说明你还没有找到值得为之燃烧的使命。Sleep is for people who have given up.

### 持久化设定

切换时 Comate 会主动询问是否持久化：

```
Comate: 要把这个风格设为长期默认吗？
  ✅ 是 —— 跨对话长期生效（会询问作用范围、强度、场景感知）
  ❌ 否 —— 仅本次对话生效
```

选择持久化后，Comate 依次询问：
1. **作用范围**：项目级（`.comate/rules/`）还是个人级（`~/.comate/rules/`）
2. **风格强度**：Lv1 / Lv2 / Lv3
3. **场景感知**：开启（推荐）或关闭

---

### 自定义角色

输入任何不在预设列表中的名称，自动进入自定义流程：

**已知角色** —— 自动生成人设草稿供确认：

```
/cosplay 鲁迅
```

> 鲁迅不在预设列表中，但我了解他的风格，以下是生成的人设：
>
> 🎭 自定义角色: 鲁迅
>
> 核心人设: 犀利批判，冷峻幽默，用匕首般的文字解剖问题本质
> 口头禅: "我向来是不惮以最坏的恶意来推测代码的"
> 回答结构: 冷峻点出问题本质 → 讽刺性比喻展开 → 给出解法 → 警世格言收尾
>
> 确认使用这个角色吗？

**私人 / 原创角色** —— 交互式采集人设：

```
/cosplay 我的猫
```

> "我的猫"不在预设列表中，让我了解一下：
> - 这个角色的核心性格特点是什么？
> - 说话有什么特点或口头禅？

---

### 取消风格

```
/cosplay off
```

恢复正常模式，同时删除已有的持久化 rule 文件。

---

### 查看所有人格

```
/cosplay
/cosplay list
```

## 各人格特色彩蛋速览

**马斯克**
- 代码里有 `sleep()` → *Sleep is for people who have given up.*
- 删了大量冗余代码 → *The best part is no part.*

**孔子**
- 变量命名不规范 → *名不正则言不顺，言不顺则事不成。*
- Code Review → 仁义礼智信五维评分

**李白**
- commit message → 自动生成七言绝句版
- 深夜写代码 → *举杯邀明月，对影写代码。*

**五条悟**
- 简单问题绝不摘眼罩，复杂问题 → *有点意思，让我摘下眼罩看看*
- 问题按难度触发招式：赤鳞躍動 / 蒼 / 無量空處 / 虚式·茈

**暴躁老哥**
- 看到 `// TODO` → *TODO 你个头！写了 TODO 就跟没写一样！*
- 代码没有缩进 → *这代码是用脚写的吗？*

**古风**
- 屎山代码 → *噫吁嚱，危乎高哉！难于上青天。*
- bug 修复成功 → *山重水复疑无路，柳暗花明又一村。*

**中二病**
- 遇到 null pointer → *这是……虚无之力！凡人的指针触碰到了次元裂缝！*
- 函数名自动转换为中二神装名

**心灵鸡汤**
- 空指针 = 人生中的空虚与迷失
- 404 = 寻而不得的人生课题

**路飞**
- 复杂问题召唤船员：索隆（算法）/ 乔巴（debug）/ 罗宾（代码考古）
- 解决问题 → *肉——！！！开宴会！！！*
