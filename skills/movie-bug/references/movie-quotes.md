# Bug 类型 × 电影台词映射库

## 空指针 / Null Reference

- 《搏击俱乐部》：你调用的那个对象……从一开始就不存在。
- 《第六感》：我看到了 null 对象。它们到处都是，它们甚至不知道自己是 null。
- 《黑客帝国》：There is no spoon. —— 你引用的对象也是。

## 死锁 / Deadlock

- 《盗梦空间》：A 等 B 释放锁，B 等 A 释放锁。我们陷入了第五层梦境，没有人记得怎么出去。
- 《教父》：我给你一个你没办法拒绝的提议……但 B 线程也给了 A 一个没办法拒绝的提议。
- 《肖申克的救赎》：有些线程注定要在等待中度过一生。

## 内存泄漏 / Memory Leak

- 《记忆碎片》：你每次都在申请内存，却从不记得要释放。就像他，每天拍下照片，却什么都记不住。
- 《美丽心灵》：那些对象，是真实的。你没有释放它们。它们一直都在。
- 《盗梦空间》：你在每一层梦境都创建了新对象，却忘了带回来。

## 无限循环 / Infinite Loop

- 《土拨鼠之日》：早上好。今天是2月2日，土拨鼠节……早上好。今天是2月2日，土拨鼠节……
- 《黑客帝国》：这是系统里的残留程序。它拒绝被删除，选择了循环。
- 《恐怖游轮》：你以为你逃出来了，其实你又回到了起点。

## 栈溢出 / Stack Overflow

- 《盗梦空间》：你递归调用得太深了。第六层梦境往下，就连时间感也会崩溃。
- 《星际穿越》：你已经进入了事件视界。数据回不来了。
- 《黑客帝国》：Neo 选择了无限递归的红色药丸。

## 并发竞态条件 / Race Condition

- 《蝴蝶效应》：两个线程同时修改了这个变量。就像他每次穿越，结果都不同——因为一切都取决于时序。
- 《回到未来》：你改变了过去的一个变量，整个时间线都乱了。
- 《源代码》：每次执行，结果都不一样。因为你无法控制时间。

## 类型错误 / Type Error

- 《变形金刚》：你以为这是一辆普通的卡车，其实它是……完全不同的类型。
- 《面具》：这个变量戴着 string 的面具，实际上它是个 number。
- 《谍影重重》：它不知道自己是什么类型。它只知道，它不是你以为的那个类型。

## 祖传屎山代码 / Legacy Code

- 《古墓丽影》：这里有上古代码。没有人知道它为什么在这里，也没有人敢动它。
- 《夺宝奇兵》：这段代码属于博物馆。
- 《木乃伊》：你打开了不该打开的文件。这些代码沉睡了千年，是有原因的。
- 《指环王》：这段代码是在暗影中铸造的。一个函数统御一切。

## 环境问题 / "我本地是好的"

- 《楚门的世界》：你的本地环境是精心布置的舞台，生产环境才是真实的世界。
- 《黑客帝国》：你服下的是蓝色药丸。在你的本地，一切正常。
- 《盗梦空间》：你怎么确定你现在不是在梦里？—— 你怎么确定你的本地环境是真实的？

## 权限错误 / Permission Denied

- 《指环王》：You shall not pass!
- 《哈利波特》：禁忌之森是有原因的。你没有访问权限。

## 超时错误 / Timeout

- 《星际穿越》：在黑洞边缘，一分钟等于七年。你的请求就卡在了那里。
- 《等待戈多》：我们在等待一个永远不会到来的响应。

## 404 / 资源不存在

- 《消失的爱人》：它曾经在那里。现在不见了。没有人知道发生了什么。
- 《寻梦环游记》：被遗忘的对象，终将从内存中消失。
