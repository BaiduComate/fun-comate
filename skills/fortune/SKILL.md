# 今日编程提示

为用户生成个人专属的今日编程趣味提示。同一用户同一天结果固定，不同用户当天结果不同。

**仅供娱乐，不构成任何技术决策建议。**

**用户请求:** $ARGUMENTS

---

## 提示生成规则

### 第一步：运行推算脚本

```bash
python3 scripts/calc_fortune.py
```

脚本输出键值对，每行一个字段：`DATE`、`USER`、`TIANGAN`、`WUXING`、`STATUS`、`ENERGY`、`BAR`。

> 若脚本执行失败，能量默认 60%，状态"稳定输出"，卡片标注"（通用版）"。

五行与状态对照：

| 五行 | 状态等级   | 能量  |
|------|-----------|-------|
| 火   | 状态爆棚   | 100%  |
| 木   | 手感火热   | 80%   |
| 金   | 稳定输出   | 60%   |
| 土   | 平平无奇   | 40%   |
| 水   | 宜摸鱼充电 | 20%   |

### 第二步：生成卡片

生成以下完整提示卡片，所有 `{占位符}` 来自脚本输出和素材库：

```
💻 今日编程提示  |  {用户名}  ·  {日期}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚡ 今日能量：{BAR}  {能量}%  {状态等级}
   {五行相生相克一句话}

✅ 今日推荐：{推荐项1} · {推荐项2} · {推荐项3}
⛔ 今日慎重：{慎重项1} · {慎重项2}
📜 今日箴言：{今日箴言}
⏰ 高效时段：{高效时段推荐}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎨 今日幸运色：{幸运色}  {推荐原因≤10字}
🎵 今日推荐歌曲：{单曲名} — {艺术家}  {推荐原因≤10字}
☕️ 今日推荐咖啡：{咖啡推荐}  {推荐原因≤10字}
🍽️ 今日推荐干饭：{美食推荐}  {推荐原因≤10字}

  以上内容仅供娱乐参考
```

**排版规则：**
- 工程区（第一个 `━━━` 内）保持紧凑，快速扫读
- 五行相生相克提示缩进在能量行下方，不并排
- 生活区每项严格单行，格式为 `emoji 标签：内容  原因`，原因跟在内容后两空格，不换行
- 原因控制在10字以内，有趣有画面感，结合五行和用户上下文
- 不显示天干、五行等推算过程，只展示结论

## 各字段生成规则

### 推荐 / 慎重 / 高效时段（动态生成）

三项均基于五行状态 + 用户上下文动态生成，不从固定列表取值。

**推荐（3项）** — 五行倾向参考：
- 火：创造性工作、头脑风暴、写新功能、提 PR
- 木：学习新框架、写设计文档、结对编程
- 金：Code Review、重构、优化性能、写测试
- 土：整理文档、清理技术债、升级依赖、日常推进
- 水：深度思考、写注释、梳理架构、适当休息

**慎重（2项）** — 五行对应风险点：
- 火（冲动）：操作生产数据库、force push
- 木（不稳）：重写核心模块、直接在 main 分支开发
- 金（保守）：忽略编译警告、不写测试直接上线
- 土（迟缓）：熬夜写代码、周五下午部署
- 水（迟缓）：删文件不备份、不充分测试就部署

**高效时段** — 基于昼夜节律 + 五行状态，格式 `HH:MM-HH:MM 适合做什么`：
- 状态爆棚 / 手感火热 → 09:00-11:00 或 15:00-17:00，深度攻坚
- 稳定输出 → 10:00-12:00，按计划推进日常开发
- 平平无奇 → 09:00-10:00，处理简单任务或会议
- 宜摸鱼充电 → 13:00-14:00 午后小憩，避开精力谷底

### 箴言库（从以下固定库中选取一条）

- 代码如人生，debug 如修行
- 今日之 bug，乃昨日之 feature
- 三思而后 commit
- 知之为知之，不知 Google 之
- 凡事预则立，不预则 Segfault
- 己所不欲，勿 push 于 main
- 天将降大任于斯人也，必先 delete node_modules
- 路漫漫其修远兮，吾将上下而 debug
- 不积硅步，无以至千行
- 朝闻 bug，夕改之

### 五行与生活推荐（动态生成）

从对话上下文感知：工作状态、情绪、口味偏好、地域、时段；无线索时按五行内在逻辑自由发挥。

**五行-相生相克提示（固定）：**
- 木：「今日木旺，水来生木更佳——多喝水，保持思路流动」
- 火：「今日火旺，木来助火——创造力爆发，适合头脑风暴」
- 土：「今日土旺，火来生土——借助团队热情，稳步推进」
- 金：「今日金旺，土来生金——扎实基础，精益求精」
- 水：「今日水旺，金来生水——沉下心，深度思考胜过快速输出」

**幸运色** — 五行对应（固定）：木-青绿、火-红紫、金-白金、土-黄棕、水-黑蓝

**BGM** — 五行风格方向（参考，非约束）：木-Lo-fi、火-电子/Hip-hop、金-古典极简、土-爵士、水-Ambient
推荐一首**真实存在**的单曲，格式：`歌曲名 — 艺术家`，不要编造曲目。

**咖啡** — 五行风味方向：木-果酸、火-浓烈、金-精品手冲、土-奶咖、水-冷萃
结合季节、时段、偏好推荐具体喝法。

**美食** — 五味对应（木-酸、火-苦、土-甘、金-辛、水-咸）
结合地域、时段、禁忌推荐具体菜品，附程序员风格理由。

## 特殊事件提醒

从上下文判断到以下情况时，在卡片后额外附加提醒：

- 函数超过200行 → "函数过长，建议拆分一下"
- 提交无 commit message → "好的 commit message 是给未来的自己写情书"
- 同一 bug 改了3次以上 → "这个 bug 有点顽固，建议换个思路或找同事一起看看"
- 代码出现 `password=123456` → "检测到硬编码密码，请立即使用安全的密钥管理方案！"
